# Suggested Sprints

## Sprint 1 — Foundation

Set up Next.js, Tailwind, Supabase, Auth, profile/roles, application shell, migrations, and RLS baseline.

## Sprint 2 — Core records

Build vehicle CRUD, mileage logs, workshops, vehicle–workshop links, and role guards.

## Sprint 3 — Services and expenses

Build maintenance type picker, contextual forms, cost logic, fuel/insurance/registration forms, and unified history.

## Sprint 4 — Value and polish

Build dashboard, reports, in-app alerts, cron processing, settings, empty/loading/error states, seeds, and permission tests.

Definition of done: each role can complete its primary flow on mobile, no unauthorized data is visible, and a seeded demo demonstrates all core features.
