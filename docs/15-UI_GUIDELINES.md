# UI Guidelines

- Design mobile first; use one-column forms and clear section spacing.
- Use red for primary actions and urgent attention only. Never use red as the default page background.
- Place the current vehicle name and plate in persistent context on vehicle-related screens.
- Separate maintenance type selection from data entry; do not present seven complex forms at once.
- Keep forms short with progressive disclosure: fuel fields only for fuel; due-date controls only for insurance/registration.
- Clearly label optional fields and show computed total/due dates before save.
- Use concise Spanish user-facing copy, for example: “Actualizar km”, “Próximo servicio”, “Todo al día”.
- Confirm destructive actions and prefer soft deletion for vehicles/workshops.
