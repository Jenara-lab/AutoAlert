# User Stories

- As an owner, I want to add several vehicles so I can manage them in one account.
- As an owner, I want to record my odometer reading so mileage-based maintenance warnings are useful.
- As an owner, I want to save a service with a total or labor/parts breakdown so my costs are accurate.
- As an owner, I want to link a vehicle to a workshop so I can view work performed by that workshop.
- As a mechanic, I want to register work through my workshop so the customer can see a reliable service history.
- As an owner, I want to log fuel, insurance, and registration so all vehicle spending is in one timeline.
- As an owner, I want an insurance or registration reminder before it expires so I avoid penalties.
- As a user, I want to filter history by month, dates, vehicle, type, and workshop so I can find a record quickly.
- As a user, I want to see upcoming services in the dashboard so I can act before problems occur.
