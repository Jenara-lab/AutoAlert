# Color System

| Token | Value | Use |
|---|---|---|
| `ink` | `#111111` | Headings, navigation. |
| `canvas` | `#F7F7F8` | App background. |
| `surface` | `#FFFFFF` | Cards and forms. |
| `line` | `#E5E7EB` | Borders/dividers. |
| `muted` | `#6B7280` | Secondary text. |
| `brand` | `#D71920` | Primary CTA and branding. |
| `brandDark` | `#A80F16` | Hover/pressed CTA. |
| `success` | `#15803D` | Completed/current states. |
| `warning` | `#D97706` | Upcoming warnings. |
| `danger` | `#DC2626` | Overdue/errors. |

Use black, white, and gray as the dominant palette. Meet WCAG contrast requirements; status color must always be paired with text or an icon.
