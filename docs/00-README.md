# AutoAlert Documentation

AutoAlert is a mobile-first vehicle maintenance management prototype. These documents are the implementation contract for a Next.js, React, TypeScript, Tailwind, Supabase, and Vercel project.

## Read in this order

1. Project overview, stack, architecture, and business rules.
2. Database, ERD, roles, use cases, and requirements.
3. Screens, navigation, components, and UI system.
4. API, notifications, security, and delivery plan.

## MVP boundaries

- No invoice, photo, file upload, booking, payment, inventory, or chat features.
- In-app alerts are required. Email and WhatsApp are optional delivery channels.
- Fixed maintenance types are used; no maintenance-type administration UI is needed.
